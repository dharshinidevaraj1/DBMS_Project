# Inventory Management System

A MySQL-based Inventory Management System that demonstrates:

- Database Design (DDL)
- Constraints
- Joins
- Views
- Stored Procedures
- Triggers
- Functions

## Database Name
inventory_db

## How to Run
1. Open MySQL Workbench.
2. Create a new query tab.
3. Execute `inventory_management.sql`.
4. The database and all objects will be created automatically.
